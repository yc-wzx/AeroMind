# 省赛 Stage 1.5 窄道安全最小修复与低速验证

日期：2026-09-27。结论：**STAGE 1.5 SAFETY FIX PARTIAL — MARGINAL**。

本报告只针对 2025 规则图推导的平面训练场。约 0.8 m 通道和墙体位置仍是 **TRAINING-ONLY / PROVISIONAL**，不是本届省赛正式场地验收结论。未进入 Stage 2，未接入 MID-360、IMU 或真实定位；`imperfect_sensors=false`。本轮没有跑 D Full、E Return，也没有提速。

## 为什么做这次修改

上一轮四层几何诊断显示：GridRoute 给出有静态余量的路线后，EGO 的 XY 局部轨迹仍会在转角切入墙侧；B/C 最贴墙处 Gazebo GT 基本跟着局部轨迹走。A 的旧目标又把起始 90° 航向改为终点 0°，导致狭窄直道内边走边转。单纯提高固定 EGO inflation 对暂定 0.8 m 通道过于保守。因此本轮按低速验证计划实施了训练场专用、默认关闭的参考分段与矩形车体安全层，并保留原始数据与参数。

## 实际改动与边界

安全层位于最终 Gazebo 速度输出之前，覆盖 EGO executor 及导航接口的低速收尾。它检查 0.05 s 间隔的已发布轨迹点，并对当前速度做 0.25 s、0.025 s 步长的离散预测；**这不是连续时间碰撞证明，也没有使 EGO 自己生成 footprint-aware 轨迹**。当前 `0.08 m` 只是训练试验门槛，不能代替实车误差预算。安全层拒绝局部路径时可能停车，是否仍能通过取决于重规划和收尾行为。

运行时参数转储确认：GridRoute clearance **0.40 m**、EGO inflation **0.22 m**、EGO 地图分辨率 **0.05 m**、vx/vy **0.25 m/s**、wz **0.30 rad/s**、规划加速度 **0.35 m/s²**，`imperfect_sensors=false`。未修改 PGM、SDF、车体尺寸、EGO inflation 或这些速度上限。转储在 `tools/results/provincial_stage15_safety_fix/actual_*_params.yaml`。

## 离线可行性与试验定义

按已有危险轨迹离线重放，A/B/C 最小车体墙距分别约 **0.062 / 0.054 / 0.014 m**；把 A 的航向保持 90°，只改变航向而不改变旧 XY，A 约 **0.186 m**，但 B/C 保持 0° 仍分别为 **0.054 / 0.014 m**。这说明 A 的 yaw 约束有帮助，而 B/C 还必须控制转角的 XY 轨迹。配置参考中心线按原几何以固定航向离线采样，三段最小墙距约 **0.14–0.19 m**，证明训练图中至少存在明显大于 0.08 m 的候选路径；该结果不保证 EGO 会跟随它。

三条单段测试的起点/目标来自 `tools/config/provincial_stage15_safety_fix_trials.yaml`：A `(4.7,0.5,90°)→(4.7,1.15)`，B `(4.7,1.15,0°)→(5.8,1.8)`，C `(5.8,1.8,0°)→(8.7,4.25)`。它们按**位置到点、保持起始航向**测试；本届比赛最终射击姿态尚未核验，所以不宣称满足射击朝向要求。旧 A 的目标 yaw=0°，与本次 A 不是同一任务。每次使用独立 Gazebo world，B/C 用 Gazebo `set_pose` 建立记录的精确初始状态。

## 剩余故障与三个误差量

B 新轨迹相对**配置参考中心线** P95 约 **0.034–0.035 m**，GT 到整条已发布 EGO 曲线的最近空间距离 P95 仅 **0.005–0.006 m**。B 的控制器没有明显横向跟丢；其余量主要取决于局部轨迹位置。C 相对配置中心线的局部指令点最大偏离约 **0.110–0.135 m**，安全层在 C04/C05/C06 分别记录 **35/35/90 条 `unsafe_plan` 状态消息**。这些是约 10 Hz 的状态采样数，**不是 35/35/90 条独立规划**。例如 C04 转入第二段 `(8.7,4.25)` 后，发布轨迹预测墙距约 **0.048 m**，安全层让最终输出速度归零。随后 C 在 `(8.647,1.800)` 附近、距目标 2.451 m 处静止并触发重试，最后到点。C 的局部轨迹切角问题仍存在，只是执行前被拦下；重试/收尾随后完成了通行。

`GT→同一时刻 EGO setpoint`、`GT→整条已发布 EGO 曲线最近点`、`GT→人工通道中心线` 是不同指标。C 在安全保持、重规划与 final approach 切换时，同步 setpoint P95 可达 **0.261 / 0.349 / 1.206 m**，并不能直接解释成控制器纯横向误差。C 的空间曲线距离 P95 为 **0.149 / 0.140 / 0.119 m**，也受“实际 final approach 命令并非 EGO 曲线”的影响。今后的控制评价必须按输出来源与阶段切分，不能把中心线偏差统一叫 tracking error。

试验过额外 0.6 m 转后锚点，C07–09 虽 3/3 到点，但一次最小墙距仅 **0.088 m**、一次出现 3 次重试，表现不一致。该实验锚点**已从最终代码移除**，日志保留，不计入验收。B01 曾因两个 Gazebo server 同时发布同一 world，里程计混流；已标记 **INVALID** 并排除。其后矩阵脚本在每次启动前检查单一 server，并在结束时清理整个进程组。

## 验证、限制和下一步

几何模块 4 个单元测试通过；改动 Python 文件 `py_compile` 通过；`colcon build --packages-select uav_planning uav_bringup --symlink-install` 两包通过；相关 `git diff --check` 通过。逐次 CSV、事件、launch 日志、summary 和汇总均在 `tools/results/provincial_stage15_safety_fix/`，图为 `trial_b_before_after.png`、`trial_c_before_after.png`。仓库原有大量未提交改动，本轮未清理或回滚。原 `tools/results/provincial_low_speed/` 历史数据保留。

目前**不应**将本轮称为省赛正式通行验收，也不应运行 D/E 或提速。下一步应在 Stage 1.5 内集中解决 C：对被拒绝的 EGO 曲线做分阶段、分规划实例的定位，找出产生转角切入的确切约束/边界；在不改 `.40/.22` 和场地几何的前提下，尝试最小的局部走廊或阶段目标改动，要求 C 三次重复均无反复安全保持、无重试且墙距有稳定余量，再复测 A/B/C。之后取得本届省赛起点、射击区、墙体与通道实测尺寸，重建 arena/PGM/collision 并重复离线和低速验证。实车可接受的安全门槛还需加入尺寸公差、定位、控制与传感器误差，不能沿用训练图的 0.08 m 直接定论。
