## 怎么测：单位 mm，未知不要填0

把底盘圆心在地面的投影作为 B；把云台竖直转轴与地面的交点作为 P。
先在底盘上标记固定参考正前方，把云台对准这个方向，记为“零位”。
这个零位是本轮测量定义，不自动等同于电控编码器零位。
此时 +X朝前、+Y朝左、+Z朝上。

M 指雷达65×65 mm外壳安装面的中心（带M3螺孔的平面），不含侧面的航插。
这里用中心投影量水平偏移；不是让操作者找内部IMU芯片。

| 填写项 | 实物量法 |
|---|---|
| B→P 的 x/y | 云台转轴相对底盘圆心的前后、左右偏移 |
| P→M 的 x/y | 零位时雷达安装面中心相对转轴的前后、左右偏移 |
| M 高度 | 安装面到地面的竖直距离；倒装时这块面在雷达上方 |
| 原生雷达 +X 朝向 | 结合官方坐标图，与云台正前方同向记0°、反向180°，其他角度如实记录；没确认留空 |
| 来源 | 实测工具/操作者/日期，明确同轴也需确认来源 |

倒装安装面离地不小于500 mm为官方打印页9的要求；工具单独报告是否满足，
不会把低高度标记为符合，也不会根据仿真高度补齐。
工具以理想倒装且仅yaw转动模型计算；小roll/pitch误差尚未标定。

```bash
python3 -B tools/hardware/mid360_mount_check/check_measurements.py /实际测量表.json \
  --output /新报告.json
```

缺测/缺来源/非有限值返回2，geometry_candidate为null，不用零补齐。
完整输入仅表示测量表字段齐备，永远不会设置navigation_ready=true。

安装面→光学原点→内部IMU依次组合；只给出候选几何，不接入实时定位。
高度或反馈问题独立列出，不被字段完整状态掩盖。
